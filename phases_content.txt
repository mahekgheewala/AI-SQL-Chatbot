backend/db/connection.py
Provides a single function get_connection(dbname) that returns a live psycopg2 connection. Uses credentials from .env. Handles connection errors and raises a clean HTTP 500 if the database is unreachable.
import psycopg2
from dotenv import load_dotenv
import os
load_dotenv()
def get_connection(dbname: str):
return psycopg2.connect(
host=os.getenv("DB_HOST"),
port=os.getenv("DB_PORT"),
user=os.getenv("DB_USER"),
password=os.getenv("DB_PASSWORD"),
dbname=dbname
)
All routes that need a DB connection call this function. Connections are opened per-request and closed in a finally block to avoid connection leaks.
backend/db/schema_fetcher.py
Contains two core functions:
fetch_all_databases() Connects to the postgres admin DB and queries pg_database to return a list of user-created database names (excluding system DBs like template0, template1, postgres).
SELECT datname FROM pg_database
WHERE datistemplate = false AND datname NOT IN ('postgres')
ORDER BY datname;
fetch_schema(dbname: str) -> dict Connects to the specified database and queries information_schema.columns to build a dictionary of the form:
{
"employees": ["id", "name", "salary", "department_id"],
"departments": ["id", "name", "location"]
}
SQL used:
SELECT table_name, column_name
FROM information_schema.columns
WHERE table_schema = 'public'
ORDER BY table_name, ordinal_position;
backend/state/metadata_store.py
A simple in-memory Python module-level dictionary acting as a lightweight cache.
_store = {
"databases": [],          # List[str] of available DB names
"selected_db": None,      # str — currently selected database name

}
def get_metadata(): ...

This store is module-level so it persists across requests within a single server process. It resets on server restart. Phase 6 (Memory System) will extend this pattern for conversation history.
backend/routers/schema.py
Exposes three endpoints:
GET /api/databases Calls fetch_all_databases(), stores result in metadata_store, and returns the list.
@router.get("/databases")
async def list_databases():

POST /api/select-database Accepts { "database": "hr_db" }, fetches its schema, stores both in metadata_store.
@router.post("/select-database")
async def select_database(request: SelectDBRequest):

set_selected_db(request.database)

GET /api/schema Returns the currently cached schema from metadata_store without hitting the DB again.

backend/ai/gemini_client.py
Initialises the Gemini SDK once at module load time. Exposes a single async-friendly function generate_sql(prompt: str) -> str that sends the prompt to Gemini and returns the raw text response.
import google.generativeai as genai
import os
from dotenv import load_dotenv
load_dotenv()
genai.configure(api_key=os.getenv("GEMINI_API_KEY"))
model = genai.GenerativeModel("gemini-1.5-flash")
def generate_sql(prompt: str) -> str:
response = model.generate_content(prompt)
return response.text
Using a module-level model instance avoids re-initialising the SDK on every request.
backend/ai/prompt_builder.py
Assembles the final prompt string from three components:
System instructions — strict rules telling Gemini to return only SQL
Schema block — formatted table/column list from metadata_store
User question — the natural language input
SYSTEM_INSTRUCTIONS = """
You are a PostgreSQL expert. Your only job is to convert the user's question into a valid SQL query.
Rules:
- Return ONLY the SQL query. No explanations. No markdown. No backticks.
- Use ONLY the tables and columns listed in the schema below.
- Do NOT invent tables or columns that are not in the schema.
- End every query with a semicolon.
- If the question cannot be answered with the given schema, return exactly: CANNOT_GENERATE
"""
def build_prompt(schema_str: str, user_question: str) -> str:
return f"""{SYSTEM_INSTRUCTIONS}
DATABASE SCHEMA:
{schema_str}
USER QUESTION:
{user_question}
SQL QUERY:"""
The schema_str is produced by schema_fetcher.format_schema_for_prompt() from Phase 2.
Example assembled prompt sent to Gemini:
You are a PostgreSQL expert. Your only job is to convert the user's question...
DATABASE SCHEMA:
Table: employees
Columns: id, name, salary, department_id, hire_date
Table: departments
Columns: id, name, location
USER QUESTION:
Show all employees with salary above 50000
SQL QUERY:
backend/ai/sql_extractor.py
Even with strict prompting, Gemini occasionally wraps output in markdown fences (```sql ... ```) or adds a short explanation. This module cleans the response.
import re
def extract_sql(raw_response: str) -> str | None:
# Remove markdown code fences
cleaned = re.sub(r"```(?:sql)?", "", raw_response, flags=re.IGNORECASE).strip()
cleaned = cleaned.replace("```", "").strip()
if cleaned.upper() == "CANNOT_GENERATE":
return None
# Keep only the first statement if multiple are returned
if ";" in cleaned:
cleaned = cleaned.split(";")[0].strip() + ";"
return cleaned if cleaned else None
Returns None when Gemini signals it cannot generate SQL for the given question.
backend/routers/chat.py (updated)
The main chat endpoint now invokes the AI pipeline:
@router.post("/chat")
async def chat_endpoint(request: ChatRequest):
# Get cached schema from Phase 2
schema = get_metadata()["schema"]
schema_str = format_schema_for_prompt(schema)
# Build prompt and call Gemini

sql=None
)
return ChatResponse(reply="SQL generated successfully.", sql=sql)

Prompt Engineering Strategy

backend/validation/safety_checker.py
Parses the SQL statement and checks for dangerous or disallowed operations. Returns a SafetyResult with is_safe: bool, risk_level: str, and reason: str.
Risk Levels:
Level
Examples
Action
BLOCKED
DROP TABLE, TRUNCATE, ALTER TABLE, raw DELETE without WHERE
Reject immediately, never execute
HIGH_RISK
DELETE FROM t WHERE ..., UPDATE ... SET ...
Require explicit user confirmation
SAFE
SELECT, INSERT
Proceed to schema check
import sqlparse
from sqlparse.sql import Statement
from sqlparse.tokens import Keyword, DDL, DML
BLOCKED_KEYWORDS = {"DROP", "TRUNCATE", "ALTER", "CREATE", "GRANT", "REVOKE"}
HIGH_RISK_OPERATIONS = {"DELETE", "UPDATE"}
def check_safety(sql: str) -> SafetyResult:
parsed = sqlparse.parse(sql)[0]
statement_type = parsed.get_type()   # SELECT, INSERT, UPDATE, DELETE, etc.
# Check for DDL (DROP, CREATE, ALTER, etc.)
for token in parsed.flatten():
if token.ttype in (DDL,) and token.value.upper() in BLOCKED_KEYWORDS:
return SafetyResult(
is_safe=False,
risk_level="BLOCKED",
reason=f"Operation '{token.value.upper()}' is not allowed."
)
# DELETE without WHERE is blocked
if statement_type == "DELETE":
sql_upper = sql.upper()
if "WHERE" not in sql_upper:
return SafetyResult(
is_safe=False,
risk_level="BLOCKED",
reason="DELETE without a WHERE clause is not allowed."
)
return SafetyResult(is_safe=True, risk_level="HIGH_RISK", reason="DELETE requires confirmation.")
if statement_type == "UPDATE":
return SafetyResult(is_safe=True, risk_level="HIGH_RISK", reason="UPDATE requires confirmation.")
return SafetyResult(is_safe=True, risk_level="SAFE", reason="Query is safe.")
backend/validation/schema_checker.py
Extracts table names and column names referenced in the SQL and cross-checks them against the schema stored in metadata_store.
import re
def check_schema(sql: str, schema: dict) -> SchemaCheckResult:
available_tables = {t.lower() for t in schema.keys()}
available_columns = {c.lower() for cols in schema.values() for c in cols}
# Extract table names from FROM and JOIN clauses
referenced_tables = extract_table_names(sql)
# Extract column names from SELECT, WHERE, ORDER BY
referenced_columns = extract_column_names(sql)
invalid_tables = [t for t in referenced_tables if t not in available_tables]
invalid_columns = [c for c in referenced_columns if c not in available_columns and c != "*"]
if invalid_tables:
return SchemaCheckResult(
is_valid=False,
reason=f"Tables not found in schema: {', '.join(invalid_tables)}"
)
if invalid_columns:
return SchemaCheckResult(
is_valid=False,
reason=f"Columns not found in schema: {', '.join(invalid_columns)}"
)
return SchemaCheckResult(is_valid=True, reason="Schema check passed.")
extract_table_names uses regex patterns to find identifiers after FROM, JOIN, INTO, UPDATE. Column extraction is best-effort; * wildcards are always allowed.
backend/validation/sql_validator.py
Orchestrates both checks. Returns a unified ValidationResult.
from .safety_checker import check_safety
from .schema_checker import check_schema
from state.metadata_store import get_metadata
class ValidationResult:
passed: bool
requires_confirmation: bool
error_message: str | None
risk_level: str   # SAFE | HIGH_RISK | BLOCKED
def validate_sql(sql: str) -> ValidationResult:
# Step 1: Safety check
safety = check_safety(sql)
if safety.risk_level == "BLOCKED":
return ValidationResult(
passed=False,
requires_confirmation=False,
error_message=safety.reason,
risk_level="BLOCKED"
)
# Step 2: Schema check
schema = get_metadata()["schema"]
schema_result = check_schema(sql, schema)
if not schema_result.is_valid:
return ValidationResult(
passed=False,
requires_confirmation=False,
error_message=schema_result.reason,
risk_level="BLOCKED"
)
# Step 3: High-risk but schema-valid → needs confirmation
if safety.risk_level == "HIGH_RISK":
return ValidationResult(
passed=True,
requires_confirmation=True,
error_message=None,
risk_level="HIGH_RISK"
)
return ValidationResult(passed=True, requires_confirmation=False, error_message=None, risk_level="SAFE")

backend/db/executor.py
The core execution module. Contains a single function execute_query(sql: str, dbname: str) -> ExecutionResult.
Transaction Management:
SELECT → uses cursor.fetchall(), no commit needed
INSERT / UPDATE / DELETE → uses connection.commit() on success
Any error → connection.rollback() to undo partial changes
import psycopg2
from db.connection import get_connection
def execute_query(sql: str, dbname: str) -> ExecutionResult:
conn = None
cursor = None
try:
conn = get_connection(dbname)
cursor = conn.cursor()
cursor.execute(sql)
sql_upper = sql.strip().upper()
if sql_upper.startswith("SELECT"):
rows = cursor.fetchall()
columns = [desc[0] for desc in cursor.description]
conn.commit()
return ExecutionResult(
success=True,
operation="SELECT",
columns=columns,
rows=[list(row) for row in rows],
row_count=len(rows),
message=f"{len(rows)} record(s) found."
)
else:
conn.commit()
affected = cursor.rowcount
op = "INSERT" if "INSERT" in sql_upper else "UPDATE" if "UPDATE" in sql_upper else "DELETE"
return ExecutionResult(
success=True,
operation=op,
columns=[],
rows=[],
row_count=affected,
message=f"{op} successful. {affected} row(s) affected."
)
except psycopg2.Error as e:
if conn:
conn.rollback()
return ExecutionResult(
success=False,
operation="ERROR",
columns=[],
rows=[],
row_count=0,
message=str(e)
)
finally:
if cursor: cursor.close()
if conn: conn.close()

from collections import defaultdict
# Structure: { "session-uuid": [ {role, content}, ... ] }
_sessions: dict[str, list] = defaultdict(list)
MAX_HISTORY_TURNS = 10    # Keep last 10 exchanges to avoid token overflow
def get_history(session_id: str) -> list:
return _sessions[session_id][-MAX_HISTORY_TURNS * 2:]  # Each turn = 2 messages
def add_message(session_id: str, role: str, content: str):
"""role = 'user' or 'assistant'"""
_sessions[session_id].append({"role": role, "content": content})
def clear_session(session_id: str):
if session_id in _sessions:
del _sessions[session_id]
def session_exists(session_id: str) -> bool:
return session_id in _sessions
MAX_HISTORY_TURNS = 10 prevents prompt size from growing unboundedly. Only the most recent 10 user+assistant pairs are included.

return None   # UNKNOWN or hallucinated name → fall back to asking user

import json
def run_report_tool(data: str, title: str = "Query Report") -> str:
try:
parsed = json.loads(data)
columns = parsed.get("columns", [])
rows = parsed.get("rows", [])
except Exception:
return "Could not generate report."
lines = [f"# {title}", ""]
lines.append("| " + " | ".join(columns) + " |")
lines.append("| " + " | ".join(["---"] * len(columns)) + " |")
for row in rows[:50]:   # Limit report to first 50 rows
lines.append("| " + " | ".join(str(v) for v in row) + " |")
lines.append(f"\n_Total: {len(rows)} record(s)_")
return "\n".join(lines)

import logging
import logging.handlers
import json
import os
from datetime import datetime
LOG_DIR = "logs"
os.makedirs(LOG_DIR, exist_ok=True)
class JSONFormatter(logging.Formatter):
"""Outputs each log entry as a single JSON line for easy parsing."""
def format(self, record):
log_entry = {
"timestamp": datetime.utcnow().isoformat() + "Z",
"level": record.levelname,
"logger": record.name,
"message": record.getMessage(),
}
if hasattr(record, "extra"):
log_entry.update(record.extra)
return json.dumps(log_entry)
def setup_logger(name: str, filename: str, level=logging.INFO) -> logging.Logger:
logger = logging.getLogger(name)
logger.setLevel(level)
# Rotating file: max 5MB per file, keep 3 backups
fh = logging.handlers.RotatingFileHandler(
f"{LOG_DIR}/{filename}", maxBytes=5 * 1024 * 1024, backupCount=3
)
fh.setFormatter(JSONFormatter())
logger.addHandler(fh)
# Console handler for development
ch = logging.StreamHandler()
ch.setFormatter(logging.Formatter("%(asctime)s [%(levelname)s] %(name)s: %(message)s"))
logger.addHandler(ch)
return logger
# Create all loggers at module load
query_logger  = setup_logger("query",    "query.log")

audit_logger  = setup_logger("audit",    "audit.log")

Feature 1 — Export System
Frontend: src/hooks/useExport.js
Handles client-side generation of CSV, Excel, and PDF from the current query results. No backend round-trip needed for most exports.
import Papa from 'papaparse'
import * as XLSX from 'xlsx'
export function useExport(columns, rows) {
function exportCSV(filename = "results.csv") {
const data = rows.map(row =>
Object.fromEntries(columns.map((col, i) => [col, row[i]]))
)
const csv = Papa.unparse(data)
downloadBlob(csv, filename, "text/csv")
}
function exportExcel(filename = "results.xlsx") {
const data = [columns, ...rows]
const ws = XLSX.utils.aoa_to_sheet(data)
const wb = XLSX.utils.book_new()
XLSX.utils.book_append_sheet(wb, ws, "Results")
XLSX.writeFile(wb, filename)
}
async function exportPDF(filename = "results.pdf") {
const { jsPDF } = await import("jspdf")
const { autoTable } = await import("jspdf-autotable")
const doc = new jsPDF()
autoTable(doc, { head: [columns], body: rows })
doc.save(filename)
}
function downloadBlob(content, filename, type) {
const blob = new Blob([content], { type })
const url = URL.createObjectURL(blob)
const a = document.createElement("a")
a.href = url; a.download = filename; a.click()
URL.revokeObjectURL(url)
}
return { exportCSV, exportExcel, exportPDF }
}

Pre-built analytical queries for common database statistics.
@router.get("/analytics/table-stats")
async def table_stats():
"""Returns row counts for all tables in the selected database."""
schema = get_metadata()["schema"]
dbname = get_metadata()["selected_db"]
results = {}
for table in schema.keys():
result = execute_query(f"SELECT COUNT(*) FROM {table};", dbname)
if result.success:
results[table] = result.rows[0][0]
return {"table_stats": results}

function ResultsTable({ columns, rows }) {
const [page, setPage] = useState(0)
const [sortCol, setSortCol] = useState(null)
const [sortDir, setSortDir] = useState("asc")
const PAGE_SIZE = 20
const sorted = sortCol
? [...rows].sort((a, b) => {
const i = columns.indexOf(sortCol)
return sortDir === "asc"
? String(a[i]).localeCompare(String(b[i]))
: String(b[i]).localeCompare(String(a[i]))
})
: rows
const paged = sorted.slice(page * PAGE_SIZE, (page + 1) * PAGE_SIZE)
const totalPages = Math.ceil(rows.length / PAGE_SIZE)
return (
<div>
<table>
<thead>
<tr>
{columns.map(col => (
<th key={col} onClick={() => handleSort(col)} className="cursor-pointer">
{col} {sortCol === col ? (sortDir === "asc" ? "↑" : "↓") : ""}
</th>
))}
</tr>
</thead>
<tbody>
{paged.map((row, i) => <tr key={i}>{row.map((cell, j) => <td key={j}>{cell}</td>)}</tr>)}
</tbody>
</table>
<div className="pagination">
<button disabled={page === 0} onClick={() => setPage(p => p - 1)}>← Prev</button>
<span>Page {page + 1} of {totalPages}</span>
<button disabled={page >= totalPages - 1} onClick={() => setPage(p => p + 1)}>Next →</button>
</div>
</div>
)
}

Prompt Length Optimisation
For large schemas (many tables), include only the top 10 most relevant tables based on keyword matching with the user question:
def filter_schema_by_relevance(schema: dict, question: str, max_tables: int = 10) -> dict:
question_words = set(question.lower().split())
scored = {
table: sum(1 for col in cols if col.lower() in question_words or table.lower() in question_words)
for table, cols in schema.items()
}
top_tables = sorted(scored, key=scored.get, reverse=True)[:max_tables]
return {t: schema[t] for t in top_tables}

# Devlogs

This file was kept as a running changelog through Phase 7 (see git history /
old `README.md` versions for that narrative). It went stale after that point
while development continued — a large amount of work (Phase 8 onward) had
accumulated uncommitted before being organized into commits on 2026-08-23.

Going forward, `git log` is the source of truth for what changed and when —
duplicating it here just drifts out of sync again. Use this file only for
notes that don't belong in a commit message (e.g. context on a design
decision that spans several commits, or a dead-end that's worth remembering).
